# Yuntao Zhang — Academic Homepage

Source for the academic homepage at **zhyuntao.com** / **yuntaochn.github.io**.

## Design
A lightweight, dependency-free static site focused on research, publications, projects and academic experience.

## Local preview
Run a simple static server, for example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Structure
- `index.html` — homepage and academic content
- `assets/css/style.css` — responsive visual system
- `assets/js/main.js` — dark-mode preference and small interactions
- `assets/img/profile.jpg` — profile portrait

Content will be expanded iteratively as publications and research material are verified.
